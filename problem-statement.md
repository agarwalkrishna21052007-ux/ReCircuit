# Problem Statement

Discarded printed circuit boards contain electronic components that may remain functional even when the original board is unusable.

Manual identification, removal and testing of individual components can be time-consuming and difficult to scale.

## Objective
Develop an automated workflow that can:
1. Scan a discarded PCB.
2. Identify candidate components.
3. Select components worth recovering.
4. Remove selected components.
5. Test each recovered component.
6. Grade the component.
7. Store the result in a digital inventory.

## Success Criteria
- Detection accuracy
- Repeatable extraction
- Reliable electrical testing
- Clear pass/fail classification
- Traceable component records
- Modular design
