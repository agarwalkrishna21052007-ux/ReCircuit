# Solution Overview

ReCircuit combines computer vision, embedded control, mechanical automation and electrical testing.

The system first identifies candidate components, then performs selective recovery and validation.

## Example Output
```text
Component: Resistor
Reference: R14
Measured Value: 9.98 kΩ
Expected Value: 10 kΩ
Status: PASS
Reuse Grade: A
```

Exact fields and grading rules will be finalized during prototype testing.
